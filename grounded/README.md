# Grounded

A personal fitness coaching platform built for you. Dark mode, mobile-first, AI-powered coach.

## Features

✓ **Morning & Evening Routines** - Rise & Thrive, Restore & Rest with progress tracking  
✓ **Daily Tracking** - Log workouts A/B/C, Zumba, walking  
✓ **Workouts Tab** - Your full strength program (3 workouts per week)  
✓ **Sunday Check-in** - Weekly body metrics and The Sunday 3 (Win, Challenge, Lesson)  
✓ **Coach** - AI coaching powered by Claude, reads your week, remembers conversations  
✓ **Weekly Scorecard** - See if you're on track for your goals  
✓ **Data Export** - Download all your data as JSON anytime  

## Tech Stack

- **Frontend**: HTML/CSS/JavaScript (dark mode, mobile-responsive)
- **Backend**: Netlify Functions (serverless)
- **Database**: Firebase Firestore (free tier)
- **Coach**: Claude API (Claude Opus 4.6)

## Getting Started

1. Follow **DEPLOYMENT.md** for step-by-step setup
2. Deploy to Netlify in 15 minutes
3. Get your app live with Firebase backend
4. Start using it on your phone
